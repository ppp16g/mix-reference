# 02a. 位相合わせの実践

**低域が決まらない原因の上位。** EQをいくら触っても解決しないので、先に潰す。

## 何が起きているのか

同じ音源を複数のマイクで録ると、マイクごとに音の到達時刻が違う。到達差が半波長分になった周波数では、2本を混ぜたときに打ち消し合って音が消える。特定の帯域だけがごっそり抜ける「櫛状の凹み（コムフィルター）」になる。

**低域ほど波長が長く、少しの距離差で大きく影響を受ける。** 60Hzの波長は約5.7m、その半分の2.85mずれると完全に逆相になる。

## 確認が必要な組み合わせ

- キック（内側マイク／外側マイク）
- スネア（上／下）
- タム（上／下）
- ドラム全体（各マイク ↔ オーバーヘッド／ルーム）
- ギターアンプ（マイク2本、あるいはマイク＋ライン）
- ベース（DI ↔ アンプマイク）
- アコースティックギター（複数マイク）
- ステレオ録音全般

## 手順1：極性反転で確認する

最も簡単で、まずこれをやる。

1. 対象の2本だけをソロにする
2. 片方に位相反転（Ø / Invert / Polarity）をかける
3. **低域が減るほう、痩せるほうが正しい。** 増えるほう＝反転が必要だった、という判断

「どちらが良いか」ではなく「どちらが太いか」で判断すると迷いにくい。

**注意**：スネアの上下は、多くの場合下マイクの反転が必要（上下から挟んでいるため、振動の向きが逆）。ただし必ず耳で確認する。

## 手順2：時間軸で揃える

極性反転は180度単位の粗い調整でしかない。より正確にやるなら波形をずらす。

1. 波形表示を拡大する（サンプル単位が見えるまで）
2. 基準にするトラック（多くはオーバーヘッド、またはキック内マイク）を決める
3. 他のトラックの波形を、アタックの立ち上がりが揃うように前後にずらす
4. **ずらしすぎない。** 揃えることで空気感が失われることがある

**ドラムの場合の基準**：オーバーヘッドを基準にして、キックとスネアをそこへ寄せると自然になりやすい。逆にキックを基準にすると、タイトだが平板になることがある。

## 手順3：オールパスフィルター

周波数ごとに位相を回すツール（オールパス／位相回転）を使うと、時間をずらさずに位相関係を調整できる。

- キックとベースの関係を詰めるときに特に有効
- 低域だけの位相を回して、2つが重なったときに最も低域が出る位置を探す
- 専用プラグインのほか、多くのEQに搭載されている

## DI とアンプの組み合わせ

ベースやギターでよくある構成。

1. DIは電気的に直結なので遅延ゼロ、アンプマイクはマイクまでの距離ぶん遅れる
2. **DI側を遅らせて、アンプマイクに合わせる**（DIにディレイを挿し、サンプル単位で調整）
3. または、アンプマイク側の波形を前へずらす
4. 合った位置では低域が最も太くなる

## 確認

- **モノにして確認する。** 位相の問題はモノで最も露骨に出る
- 位相を合わせた後、低域の量が変わっているのでEQをやり直す必要がある。**だからこの作業を先にやる**
- ドラム全体をソロにして、各マイクを1本ずつ足していく。足すたびに音が太くなるなら正しい。痩せたらそのマイクに問題がある
