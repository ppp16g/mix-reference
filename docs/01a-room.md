# 01a. スピーカー設置と部屋の対処

高価なスピーカーを適当に置くより、安いスピーカーを正しく置くほうが良い判断ができる。**部屋の影響はスピーカーの性能差より大きい。**

## 設置の手順

1. **正三角形を作る。** 左右スピーカーの間隔と、自分の耳までの距離を等しくする。1.0〜1.5mが一般的
2. **ツイーターを耳の高さに合わせる。** スタンドか、机上なら台を使う。数センチのずれで高域の聞こえ方が変わる
3. **内振り（トーイン）** させ、軸が自分の少し後ろで交わるようにする
4. **左右対称に置く。** 片側だけ壁に近い、片側だけ本棚がある、という状態は定位を狂わせる
5. **背面の壁から離す。** 最低20cm、できれば40cm以上。壁に近いほど低域が過剰に持ち上がる
6. **部屋の短辺方向に向けて座る**のが基本。長辺方向より定在波の影響を受けにくい

## 机の反射

デスクトップに置く場合、机の天板からの反射が中域を濁らせる。

- スピーカーを机の縁から離す
- スピーカーと自分の間の机上に、吸音材や布を置く。厚手のブランケットを試すだけでも変化が分かる
- ノートPCのディスプレイやモニターがスピーカーの前に出ていると、反射源になる

## 部屋の低域

**低域は部屋の寸法で決まる定在波の影響を受け、特定の周波数だけが極端に大きく／小さく聞こえる。** ミックスで低域が決まらない最大の原因がこれ。

- **座る位置を変えるだけで大きく変わる。** 部屋の前後方向の中央（長さの50%）は最も谷ができやすいので避ける。おおよそ38%あたりが目安としてよく挙げられる
- **部屋の隅に吸音材（ベーストラップ）** を置くのが最も効果が大きい。低域は隅に溜まる
- 完全な対策は現実的でないことが多い。**「自分の部屋の癖を知る」ことで代替できる**

### 癖の把握のしかた

1. 低域の量が信頼できる市販曲を5曲用意する
2. 自分の部屋で聴き、ヘッドホンでも聴く
3. どの帯域が部屋で誇張／不足して聞こえるかをメモする
4. 以後、その分を割り引いて判断する

たとえば「うちは80Hzが膨らんで聞こえる」と分かっていれば、ミックス時に80Hzを削りすぎるミスを防げる。

## ヘッドホンの併用

**低域の判断はヘッドホンのほうが信頼できる場合が多い。** 部屋の影響を受けないため。

- 開放型は空間の把握がしやすく、密閉型は遮音性が高い
- **ヘッドホンだけでミックスすると起きること**：リバーブが少なくなる、ステレオが広くなりすぎる、低域を入れすぎる／抜きすぎる
- スピーカーとヘッドホンを行き来し、両方で成立する状態を探す

## 補正ソフトについて

測定用マイクで部屋の特性を測り、補正をかけるソフトがある。有効だが、万能ではない。

- **効くのは中高域の反射由来の凹凸。** 低域の定在波（谷）は補正で埋めきれない
- 補正に頼りすぎると、他の環境での判断ができなくなる
- 導入しても、リファレンス曲との比較（[リファレンス曲の使い方](01c-reference.md)）はやめないこと
