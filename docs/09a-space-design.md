# 09a. 空間設計の実例

「リバーブをかける」ではなく「どこに置くか決める」。**距離を設計する作業。**

## 3層で考える

| 層 | 距離感 | 手段 |
|---|---|---|
| 前景 | 目の前 | リバーブ少、プリディレイ長め、高域そのまま |
| 中景 | 数メートル | リバーブ中、少しハイカット |
| 後景 | 部屋の奥 | リバーブ多、ハイカット強め、音量小 |

**全部を同じ距離に置くと、平坦になる。** ボーカルとキックは前、パッドとコーラスは奥、という具合に振り分ける。

## 標準的なFX構成

3系統を用意すると、たいていの曲に対応できる。

### FX1：ショートルーム（接着用）

| 項目 | 設定 |
|---|---|
| タイプ | Room / Ambience |
| Decay | 0.4–0.8秒 |
| Pre-Delay | 0–10ms |
| ハイパス | 200–400Hz |
| ハイカット | 6–8kHz |

**用途**：ドラム全体、ギター、鍵盤を薄く送り、「同じ部屋にいる」感を作る。単体では聞こえないくらいの量でよい。

### FX2：プレート／ホール（演出用）

| 項目 | 設定 |
|---|---|
| タイプ | Plate（ポップス）/ Hall（バラード、壮大な曲） |
| Decay | 1.2–2.0秒（テンポによる） |
| Pre-Delay | 20–40ms |
| ハイパス | 200–300Hz |
| ハイカット | 8–10kHz |

**用途**：ボーカル、スネア、リード楽器。存在感を出しつつ奥行きを作る。

### FX3：テンポ同期ディレイ

| 項目 | 設定 |
|---|---|
| Time | 付点8分（跳ねた感じ）、8分、4分 |
| Feedback | 15–30%（1〜3回返る程度） |
| ハイパス | 300–500Hz |
| ハイカット | 4–6kHz |
| 幅 | ステレオまたはピンポン |

**用途**：ボーカル、リード。リバーブより濁らずに広がりを作れる。

---

## ディケイの決め方

**曲のテンポより長いと濁る。**

- 目安：4分音符の長さ（60000 ÷ BPM ミリ秒）× 2〜4 程度
- BPM120 → 4分は500ms → ディケイ1.0〜2.0秒
- BPM90 → 4分は667ms → ディケイ1.3〜2.7秒
- テンポが速い曲、音数の多い曲は短く

**確認**：残響が次のコードチェンジまでに消えているか。残っているなら短くする。

## プリディレイの効果

**原音と残響を時間的に分離する。** これが明瞭度を守る最大のポイント。

| プリディレイ | 効果 |
|---|---|
| 0–10ms | 音と残響が一体化。近い、狭い印象 |
| 20–40ms | 原音が前に出る。言葉が聞き取りやすい |
| 50–100ms | 明確に離れる。プレディレイが独立したエコーとして聞こえ始める |

**ボーカルは20–40msが扱いやすい。** テンポ同期（8分や16分）にすると、リズムに馴染む。

---

## リバーブが濁るときの手順

上から順に試す。

1. **リターンにEQを挿してハイパス。** 200–400Hzまで切っても、量感はほとんど減らない
2. **ハイカット。** 8kHz前後。シャリつきが消えて自然になる
3. **プリディレイを伸ばす。** 20→40ms
4. **ディケイを短くする**
5. **キックをトリガーにサイドチェイン**（[サイドチェイン実践](06a-sidechain-recipes.md)）
6. **量を減らす**

---

## 実例：ポップスのボーカル

```
Vo (dry)
 ├→ FX2 プレート（Pre-Delay 30ms, Decay 1.5s）… -18dB程度
 └→ FX3 ディレイ（付点8分, FB 20%）… -22dB程度
```

- サビだけディレイのセンドを +3dB する（オートメーション）
- フレーズの終わりだけディレイを送ると、言葉を邪魔せず広がる
- ボーカル用リバーブに、ボーカル自身をトリガーにしたダッキングを入れるとさらに明瞭

## 実例：バンドのドラム

```
Kick    → FX1 ルーム（ごく少量、またはゼロ）
Snare   → FX1 ルーム（多め）+ FX2 プレート（少量）
Tom     → FX1 ルーム（多め）
OH/Room → 送らない（既に空間が入っている）
```

- キックにリバーブを送ると低域が濁る。基本は送らないか、ごく少量
- スネアは2系統に送ると、近さと広がりを両立できる

## 実例：奥に引っ込ませたいパッド

```
Pad
 ├ ローパス 6kHz（高域を削る）
 ├→ FX2 ホール（多め、Pre-Delay 0ms）
 └ 音量を下げる
```

高域を削る＋リバーブを増やす＋音量を下げる、の3つを同時にやると、はっきり奥に行く。

---

## 確認

- **リバーブをすべてバイパスして聴く。** 寂しくなるなら適量、変わらないなら不要、スッキリするなら多すぎ
- **小音量で確認。** 残響の量は小さい音で判断しやすい
- **モノで確認。** ステレオリバーブはモノにすると量が変わることがある
