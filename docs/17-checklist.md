# 17 チェックリストと書き出し

## 書き出し前チェックリスト

### 技術面
- [ ] 全リージョンにフェードがかかっている（クリックノイズなし）
- [ ] 意図しないミュート／ソロが残っていない
- [ ] モニター用プラグイン（モノ化、リファレンス比較など）を外した
- [ ] ミックスバスのピークが -6 dBFS 程度に収まっている
- [ ] クリッピングしているトラックがない
- [ ] 曲の頭と尻に余白がある（後処理のため）
- [ ] ノイズ、リップノイズ、不要な残響が残っていない

### 音楽面
- [ ] 通しで最後まで違和感なく聴けた
- [ ] ボーカル（主役）が全区間で聞き取れる
- [ ] セクション間に起伏がある
- [ ] 低域の量がリファレンスと大きくずれていない
- [ ] 一番聴かせたい箇所が実際に一番印象的になっている

### 環境チェック
- [ ] モニタースピーカー
- [ ] ヘッドホン
- [ ] イヤホン
- [ ] スマホ／ノートPCの内蔵スピーカー
- [ ] モノラル
- [ ] 小音量（別室から聞こえる程度）
- [ ] 車（可能なら）

**小音量とスマホでのチェックは特に有効。** バランスの破綻が明確に出る。

### 時間を置く
- [ ] 一晩以上あけて聴き直した
- [ ] 他人に聴いてもらった（可能なら）

## 書き出し設定

**マスタリングに回す／自分でマスタリングする場合**
- 形式：WAV
- ビット深度：24bit（32bit floatでも可）
- サンプルレート：**プロジェクトと同じ**（変換しない）
- ディザ：**なし**（24bit以上で出すなら不要）
- ピーク：-6 dBFS 程度に余裕を残す
- ミックスバスのリミッターは外す

**配信用の最終形として出す場合** → [マスタリングとラウドネス](18-mastering.md)

## 併せて出しておくと便利なもの

- **インストゥルメンタル版**（ボーカル抜き）
- **ステム**（ドラム／ベース／楽器／ボーカル／FX の5〜8系統）— 後からの修正、ライブ、リミックスで役に立つ
  - ステムは全て曲頭から同じ長さで出す
  - ミックスバス処理は含めるか外すかを決めて統一

## セッションの保存

- 書き出しと同時に、そのバージョンのセッションを別名保存
- 「Mix v3 (final)」より日付入りの方が後で混乱しない
