# 05a. 楽器別コンプ設定の出発点

数値は**探し始める位置**であって、正解ではない。テンポ・演奏・音源で大きく動く。

## 設定の手順（共通）

1. **Ratioを決める**（軽く整えるなら2:1〜3:1、しっかり抑えるなら4:1〜6:1）
2. **Attack/Releaseを暫定で置く**（下の表の値）
3. **Thresholdを下げていき、GRメーターが目標値まで動く位置**にする
4. **Attackを調整** — アタック感が欲しければ遅く、丸くしたければ速く
5. **Releaseを調整** — GRメーターが曲のリズムに合わせて呼吸する位置
6. **Makeup Gainで音量を戻し**、バイパスABで確認

**リリースの目安**：4分音符の長さ = 60000 ÷ BPM ミリ秒。BPM120なら500ms、BPM90なら667ms。8分なら半分。

---

## キック

| 項目 | 目安 |
|---|---|
| Ratio | 4:1 |
| Attack | 10–30ms（アタックを通す） |
| Release | 80–150ms |
| GR | 3–6dB |

- アタックを速くすると打点が丸くなる。パンチが欲しければ遅め
- 打ち込みで既に音量が揃っているなら、コンプは不要なことも多い

## スネア

| 項目 | 目安 |
|---|---|
| Ratio | 4:1 |
| Attack | 5–20ms |
| Release | 100–200ms（次の打点前に戻る） |
| GR | 3–6dB |

- 胴鳴りを引き出したければリリースを遅めに
- ゴーストノートを聴かせたければ、GRを深めにして粒を揃える

## ドラムバス

| 項目 | 目安 |
|---|---|
| Ratio | 2:1〜4:1 |
| Attack | 20–30ms |
| Release | テンポ同期、または Auto |
| GR | 2–4dB |

- **接着が目的。** 潰すのはパラレルの役目（[パラレル処理](05b-parallel.md)）
- リリースが遅いとポンピングする。GRメーターが拍に合わせて戻っているか確認

---

## ベース

**最もコンプが要る楽器。** 音程による音量差が大きい。

| 項目 | 目安 |
|---|---|
| Ratio | 4:1〜6:1 |
| Attack | 10–30ms |
| Release | 100–250ms |
| GR | 4–8dB |

- **2段掛けが有効。** 1段目で速めに飛び出しを抑え、2段目で遅めに全体を均す
- Opt系（光学式）は滑らかで、ベースに向く
- コンプ前にクリップゲインで大きく暴れる音を均しておくと、コンプが軽くて済む

---

## エレキギター

| 項目 | 目安 |
|---|---|
| Ratio | 2:1〜4:1 |
| Attack | 10–30ms |
| Release | 100–200ms |
| GR | 2–5dB |

- **歪んだギターは既に圧縮されている。** コンプは軽くてよい、あるいは不要
- クリーン、カッティングは効果が大きい

## アコースティックギター

| 項目 | 目安 |
|---|---|
| Ratio | 3:1 |
| Attack | 15–30ms（ピックのアタックを残す） |
| Release | 150–300ms |
| GR | 3–6dB |

## ピアノ

| 項目 | 目安 |
|---|---|
| Ratio | 2:1〜3:1 |
| Attack | 20–40ms |
| Release | 200–400ms |
| GR | 2–4dB |

- 強くかけると響きが持ち上がって濁る
- ダイナミクスが演奏の表現そのものなので、慎重に

---

## ボーカル

**2段掛けを基本にする。** 1台で8dB下げるより、2台で4dBずつのほうが自然。

**1段目（ピークを抑える）**

| 項目 | 目安 |
|---|---|
| タイプ | FET系（速い） |
| Ratio | 4:1〜6:1 |
| Attack | 3–10ms |
| Release | 50–100ms |
| GR | 3–5dB（飛び出したところだけ） |

**2段目（全体を均す）**

| 項目 | 目安 |
|---|---|
| タイプ | Opt系（滑らか） |
| Ratio | 2:1〜3:1 |
| Attack | 遅め、または固定 |
| Release | 遅め |
| GR | 2–4dB（常に動いている） |

**その前にオートメーション。** 手で音量を揃えてからコンプすると、この設定で十分足りる（[ボーカルチェーンの実例](13a-vocal-chain.md)）。

---

## ミックスバス

| 項目 | 目安 |
|---|---|
| Ratio | 2:1（またはそれ以下） |
| Attack | 30ms前後（遅め、アタックを通す） |
| Release | テンポ同期 or Auto |
| GR | 1–3dB |

**これ以上は潰さない。** ミックスバスのコンプは「まとまり」を出すためのもので、音圧を稼ぐ場所ではない。

---

## コンプが要らないケース

- 打ち込みで既に音量が均一
- 演奏が非常に安定している
- ダイナミクスそのものが表現である（ピアノソロなど）
- **オートメーションで解決すべき問題**（セクション間の音量差はコンプでは直らない）
