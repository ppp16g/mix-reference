# 12a. ドラム処理チェーンの実例

生ドラム、打ち込みそれぞれの標準的な組み立て方。**そのまま使うのではなく、構造の参考に。**

## 生ドラムの手順

### 1. 下ごしらえ
- 位相確認（[位相合わせの実践](02a-phase.md)）
- 不要区間のカット、フェード
- タムのミュート／ゲート

### 2. オーバーヘッド／ルームから作る

**ここがドラムの本体。** シンバル用のマイクだと思わないこと。

```
OH: ハイパス 80–120Hz
  → EQ: 400–800Hz を -2dB（濁り）
  → EQ: 10kHz シェルフ +1〜2dB（空気感）
```

この状態で「ドラムとして聴ける」ところまで持っていく。

### 3. キックとスネアを足す

**足すたびに音が太くなるのが正しい。** 痩せたら位相を疑う。

```
Kick: ハイパス 30Hz
  → EQ: 60Hz +2dB / 300Hz -3dB / 3kHz +2dB
  → Comp: Ratio 4:1, Attack 20ms, Release 100ms, GR 4dB
  → (必要なら) トランジェントシェイパーでアタック調整
```

```
Snare: ハイパス 100Hz
  → EQ: 200Hz +2dB / 600Hz -3dB / 4kHz +2dB
  → (リングがあれば) ダイナミックEQで狭Qカット
  → Comp: Ratio 4:1, Attack 10ms, Release 150ms, GR 4dB
  → サチュレーション（軽く）
```

### 4. その他を足す

```
Hat: ハイパス 400Hz
  → EQ: 8kHz付近をダイナミックEQで抑制（刺さり対策）
```

```
Tom: ハイパス 60Hz
  → EQ: 500Hz -3dB / 4kHz +2dB
  → ゲートまたはミュートオートメーション
```

### 5. ドラムバス

```
Drum Bus:
  Comp: Ratio 2:1, Attack 30ms, Release テンポ同期, GR 2–3dB
  → サチュレーション（軽く）
  → EQ: 必要なら全体の微調整（±1dB程度）
```

### 6. パラレルコンプ

```
Drum → (Send) → Parallel Bus:
  ハイパス 100Hz
  → Comp: Ratio 10:1, Attack 3ms, Release 50ms, GR 12dB
  → サチュレーション
  → 原音に少しずつ足す
```

詳細は[パラレル処理の実践](05b-parallel.md)。

## 打ち込みドラムの手順

### 1. まずMIDIを直す

**プラグインより先にここ。**

- ベロシティにばらつきをつける。全部同じだと機械的
- タイミングを微調整。完全なグリッドは不自然（ジャンルによる）
- ゴーストノートを足すと生っぽくなる
- **サンプルの質が最優先。** EQで直そうとする前に、別のサンプルを試す

### 2. パーツごとにトラックを分ける

1つのステレオ出力でまとめず、キック／スネア／ハット／その他に分離する。個別処理ができないと打つ手が減る。

### 3. 処理

生ドラムと同様だが、

- サンプルは既に処理済みのことが多いので、**EQもコンプも軽く**
- レイヤー（アタック用サンプル＋低域用サンプル）が有効。特にキック
- レイヤーしたら**必ず位相を確認**

### 4. ドラムバス

生ドラムと同じ。打ち込みでも、バスでまとめる効果は大きい。

## 「バラバラに聞こえる」ときの対処

音は良いのに一体感がない、という症状。

1. **ドラムバスのコンプ**（GR 2–4dB）で接着する
2. **共通のルームリバーブ**に全パーツを送る。同じ空間に置く
3. **パラレルコンプ**で密度を足す
4. **バス全体にサチュレーション**を軽く

打ち込みで特に起きやすい。各パーツが別々の場所で録られたサンプルなので、共通の空間情報がないため。

## 「うるさいのに迫力がない」ときの対処

1. **中高域が過多**。2–5kHzがハット、スネア、シンバルで重なっている
2. ハットの音量を下げる。ハイパスを高めに
3. **低域の土台を確認**。キックが80Hz以下を持っているか
4. パラレルコンプで密度を足す（音量ではなく密度で迫力を出す）
