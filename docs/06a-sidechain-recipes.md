# 06a. サイドチェイン実践レシピ

トリガーの選び方、周波数、深さ、時定数をケースごとに。すべて**出発点**であり、耳で詰める。

## 共通の設定手順

1. 処理する側（譲る側）にダイナミックEQを挿す
2. トリガー側からサイドチェイン入力へセンド（**プリフェーダー**にしておくと安定する）
3. 問題の帯域にバンドを置き、Dynamics を有効化
4. **Rangeを一時的に -12dB** にして、動きを分かりやすくする
5. Threshold を動かし、狙ったタイミングだけ動く位置を探す
6. Range を実用値へ戻す
7. Attack / Release を詰める
8. バイパスAB

---

## 1. キック → ベース（最頻出）

| 項目 | 設定 |
|---|---|
| トリガー | **キック単体**（ドラムバスは不可） |
| 処理側 | ベース |
| 周波数 | キックの基音（50–80Hz）。アナライザーでキックのピークを確認して合わせる |
| Q | 1.0–2.0（ベル） |
| Range | -2〜-4dB |
| Attack | 1–10ms |
| Release | 50–150ms |

**確認方法**：キックとベースだけをソロにして、キックの打点でベースが軽く引くのが見えるか。ポンピングとして聞こえるなら深すぎる。

**うまくいかないとき**
- ドラムバス全体をトリガーにしていないか
- 帯域が広すぎないか（シェルフではなくベルで）
- 常時ぶつかっているなら、そもそも周波数の住み分けから見直す（[低域の実践](11a-kick-bass.md)）

## 2. ボーカル → シンセ／パッド

| 項目 | 設定 |
|---|---|
| トリガー | ボーカル（バス全体でよい） |
| 処理側 | シンセ、パッド、ストリングス |
| 周波数 | 1–4kHz（ボーカルの明瞭度帯域） |
| Q | 0.8–1.5 |
| Range | -2〜-5dB |
| Attack | 5–20ms |
| Release | 100–300ms |

**効果**：ボーカルの音量を上げずに、聞き取りやすさだけを改善できる。**歌っていないところではシンセがフルで鳴る**ので、寂しくならない。

**リリースを長めに**すると、フレーズ全体で自然に引いてくれる。短いと音節ごとにパクパクして不自然。

## 3. ボーカル → ギター

| 項目 | 設定 |
|---|---|
| 周波数 | 2–4kHz |
| Range | -2〜-4dB |
| Release | 150–300ms |

歪みギターは帯域を広く占領するので、これが効く。左右のギターに同じ設定を入れる。

## 4. スネア → ギター／キーボード

| 項目 | 設定 |
|---|---|
| 周波数 | 200–400Hz |
| Range | -2〜-3dB |
| Attack | 1–5ms |
| Release | 50–100ms |

スネアの胴の帯域を空ける。効果は控えめだが、密度の高いミックスで効く。

## 5. キック → リバーブのリターン

**見落とされがちだが効果が大きい。**

| 項目 | 設定 |
|---|---|
| トリガー | キック |
| 処理側 | リバーブのFXチャンネル |
| 周波数 | 低域全体（ローシェルフ）または 100–300Hz |
| Range | -3〜-6dB |
| Release | 100–200ms |

リバーブの低域がキックと重なって濁るのを防ぐ。リバーブ自体をハイパスするのと併用してよい。

## 6. ボーカル → リバーブのリターン

| 項目 | 設定 |
|---|---|
| トリガー | ボーカル |
| 処理側 | ボーカル用リバーブ |
| 周波数 | 全域（またはシェルフ） |
| Range | -3〜-6dB |
| Release | 200–400ms |

**歌っている間はリバーブが引っ込み、フレーズが切れた瞬間に残響が出る。** リバーブを深くかけても言葉が埋もれない。バラードで特に有効。

## コンプのサイドチェインとの違い

| | ダイナミックEQ | コンプ |
|---|---|---|
| 影響範囲 | 指定した帯域のみ | 全帯域 |
| 用途 | 自然な整理 | 効果としてのポンピング |
| 向くジャンル | 全般 | ダンス、EDM |

**ダンス系で「ズンズン」というポンピングを狙う**なら、ダイナミックEQではなくコンプのサイドチェインを使う。GR 6–12dB、リリースをテンポに合わせて、意図的に聞こえるようにかける。

## ボリュームシェイパーという選択肢

サイドチェインの代わりに、**テンポ同期した音量カーブ**を直接描くツールもある。

- トリガー音源が不要
- 形を完全にコントロールできる
- キックが鳴っていない小節でも同じ動きになる（利点でも欠点でもある）

ダンス系では、こちらのほうが安定した結果になることが多い。
