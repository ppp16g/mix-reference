# 13a. ボーカルチェーンの実例

順序に意味がある。**特に、オートメーションがコンプより先。**

## 標準的な順序

```
1. 編集（タイミング、ピッチ、ノイズ、ブレス）
2. クリップゲイン／音量オートメーション   ← ここが最重要
3. ハイパス＋不要帯域のカット
4. コンプ 1段目（速い）
5. コンプ 2段目（遅い）
6. ディエッサー
7. 音作りのEQ（ブースト）
8. サチュレーション
9. （センドで）リバーブ、ディレイ
```

**7の後にもう一度ディエッサーを置く**構成もある。高域をブーストするとサ行も増えるため。

---

## 1. 編集

- タイミングとピッチはここで終わらせる
- リップノイズ、ノイズを個別に処理
- ブレスは消さず、**大きすぎるものだけ下げる**
- ダブル・ハモは語尾をメインに揃える

## 2. 音量を手で揃える（最重要）

**プロのミックスでボーカルのフェーダーは常に動いている。** コンプで押さえ込むのではなく、まず手で揃える。

手順：
1. ボーカルだけを再生し、フレーズごとに音量を確認
2. クリップゲインまたはオートメーションで、**全フレーズが同じ大きさに聞こえる**まで揃える
3. 単語単位で飛び出しているところも下げる

**この作業をやるとコンプが軽くて済み、結果として自然になる。** 逆にここを飛ばすと、コンプでGR 8〜10dBかけることになり、平坦で不自然な音になる。

詳細は[オートメーション実践](10a-automation-practice.md)。

## 3. 引き算のEQ

| 操作 | 周波数 | 目安 |
|---|---|---|
| ハイパス | 男声80–100Hz / 女声100–150Hz | 音色が変わらない位置まで |
| カット | 200–400Hz | こもり。必要な分だけ |
| カット | 500–800Hz | 鼻詰まり感 |
| （狭Qカット） | 特定の共振 | ブーストスイープで探す |

**特定の音程だけ膨らむ場合はダイナミックEQ。** 静的に削ると、他の部分が痩せる。

## 4. コンプ 1段目（ピークを止める）

| 項目 | 目安 |
|---|---|
| タイプ | FET系など、速いもの |
| Ratio | 4:1〜6:1 |
| Attack | 3–10ms |
| Release | 50–100ms |
| GR | 3–5dB（飛び出したところだけ） |

**常時動かさない。** メーターが時々動く程度。

## 5. コンプ 2段目（全体を均す）

| 項目 | 目安 |
|---|---|
| タイプ | Opt系など、滑らかなもの |
| Ratio | 2:1〜3:1 |
| Attack | 遅め |
| Release | 遅め |
| GR | 2–4dB（常に軽く動く） |

**1台で8dB下げるより、2台で4dBずつのほうが自然。** これが2段掛けの理由。

## 6. ディエッサー

- 対象：5–10kHz（声によって位置が違う）
- **周波数を特定する**：ディエッサーのリスニングモード（検出音のみ再生）でサ行が最も強く聞こえる位置を探す
- 深さ：3–6dB程度
- **かけすぎると「シャ」が「チャ」に聞こえる。** バイパスABで必ず確認

**代替**：ダイナミックEQでも同じことができる。むしろ帯域を細かく指定できるぶん有利なことも。

## 7. 音作りのEQ

| 操作 | 周波数 | 目安 |
|---|---|---|
| ブースト | 2–5kHz | 明瞭度、抜け |
| ブースト（シェルフ） | 8–12kHz | 空気感、艶 |
| ブースト | 100–200Hz | 太さ（必要なら、少量） |

**ブーストは広いQ（0.7–1.2）で。** 狭いブーストは不自然になる。

## 8. サチュレーション

- ごく軽く。倍音が増えると、**音量を上げずに前に出る**
- 小型スピーカーでの存在感が改善する
- かけすぎると耳障りになる

## 9. 空間系（センドで）

```
Vo → FX プレート（Pre-Delay 30ms, Decay 1.5s, ハイパス250Hz, ハイカット9kHz）
   → FX ディレイ（付点8分, FB 20%, ハイカット5kHz）
```

- **プリディレイを長め**にすると、リバーブがあっても言葉が明瞭
- ディレイのセンドは、**フレーズの終わりだけ**オートメーションで上げると効果的
- リバーブのリターンに、ボーカル自身をトリガーにしたダッキングを入れるとさらに明瞭（[サイドチェイン実践](06a-sidechain-recipes.md)）

---

## ダブル・ハモの処理

- メインより **-6〜-10dB** 程度
- **高域を少し削る**（メインより奥に置く）
- ハイパスをメインより高めに
- 左右に振る（L60/R60程度）
- メインと同じリバーブに送ると馴染む
- **メインと同じコンプ設定にしない。** より強めに潰して均一にすると、背景として機能する

---

## 埋もれるときのチェック順

音量を上げる前に、上から順に確認する。

1. **音量が揃っているか**（ステップ2をやったか）
2. **他の楽器が2–5kHzを占領していないか**。ギター、シンセ、シンバルを削る
3. **リバーブが多すぎないか**。多いほど奥に行く
4. **低〜中域がこもっていないか**。こもっていると音量を上げられない
5. **サチュレーションで倍音を足す**。音量を上げずに前に出せる
6. **ダイナミックEQで伴奏をダック**する

**音量を上げるのは最後の手段。** それで解決するなら最初から問題になっていない。
