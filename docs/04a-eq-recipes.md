# 04a. 楽器別EQの出発点

**これはプリセットではなく、出発点。** 曲・音源・演奏によって正解は動く。数値は「そのあたりから探し始める」ための目安として使う。

必ず[問題帯域の見つけ方](04b-finding.md)で自分の音を確認してから当てること。

---

## キック

| 操作 | 周波数 | 目安 |
|---|---|---|
| ハイパス | 25–35Hz | 不要な超低域を除去 |
| ブースト | 50–70Hz | 土台。ベースとの分担で位置を決める |
| カット | 200–400Hz | 段ボール感 |
| ブースト | 2–5kHz | ビーターのアタック |

- 土台の周波数は、ベースと**必ずずらす**（[低域の実践](11a-kick-bass.md)）
- アタックが足りないとき、EQで足すよりトランジェントシェイパーのほうが自然なことが多い

## スネア

| 操作 | 周波数 | 目安 |
|---|---|---|
| ハイパス | 80–120Hz | |
| ブースト | 150–250Hz | 胴の太さ |
| カット | 400–800Hz | 箱鳴り、こもり |
| ブースト | 2–5kHz | アタック、抜け |
| ブースト（シェルフ） | 8kHz〜 | スナッピーの響き |

- リング（特定音程の残響）は狭Qでピンポイントにカット
- 上下2本ある場合、下マイクは高域中心、上マイクは胴の成分中心にすると住み分く

## ハイハット／シンバル

| 操作 | 周波数 | 目安 |
|---|---|---|
| ハイパス | 300–600Hz | 高めに切ってよい |
| カット | 1–2kHz | 硬さ、うるささ |
| カット | 6–10kHz | 刺さり（ダイナミックEQ推奨） |

|---|---|---|
| ハイパス | 50–80Hz | |
| ブースト | 80–150Hz | 低いタムの胴 |
| カット | 400–600Hz | ボワつき |

| 操作 | 周波数 | 目安 |
|---|---|---|
| ハイパス | 60–120Hz | 切りすぎない。ドラムの本体はここにある |
| カット | 400–800Hz | 濁り |
| ブースト（シェルフ） | 10kHz〜 | 空気感 |

## ベース

| 操作 | 周波数 | 目安 |
|---|---|---|
| ハイパス | 30–40Hz | |
| ブースト | 60–100Hz | 土台（キックとずらす） |
| カット | 200–400Hz | ボワつき |
| ブースト | 700Hz–1.5kHz | 音程感、輪郭 |
| ブースト | 2–3kHz | 指／ピックのアタック |

- **小型スピーカー対策として、中域の存在感が重要**（[低域の実践](11a-kick-bass.md)）
- シンセベースも基本は同じ。ただし倍音構成が音源依存なので、より個別対応が必要

---

## エレキギター（歪み）

| 操作 | 周波数 | 目安 |
|---|---|---|
| ハイパス | 80–120Hz | ベースと分ける |
| カット | 200–400Hz | 濁り |
| カット | 400–800Hz | 箱鳴り |
| ブースト | 1–3kHz | 抜け（ボーカルと要調整） |
| ローパス | 8–12kHz | ノイズとシャリつき |

- **ボーカルと帯域が完全に被る。** ギター側の2–4kHzを削るか、ダイナミックEQでダック
- ダブルトラックの場合、左右でわずかに違うEQにすると広がる

## アコースティックギター

| 操作 | 周波数 | 目安 |
|---|---|---|
| ハイパス | 80–120Hz | 弾き語り以外なら高めでよい |
| カット | 150–250Hz | ボワつき（サウンドホールの鳴り） |
| カット | 400–600Hz | こもり |
| ブースト | 2–5kHz | ピックのアタック |
| ブースト（シェルフ） | 8kHz〜 | 弦の擦れ、空気感 |

## ピアノ

| 操作 | 周波数 | 目安 |
|---|---|---|
| ハイパス | 役割による | 伴奏なら100–200Hz、主役なら低め |
| カット | 200–400Hz | 濁り |
| カット | 1–2kHz | 硬さ |
| ブースト | 5–10kHz | きらびやかさ |

**役割を先に決める。** 全域を鳴らそうとすると必ず他とぶつかる。

## シンセ・パッド

- **ハイパスとローパスで帯域を切り出す**のが基本。中域を全部持っていくため
- 具体的な周波数は音源次第。全体を聴きながら、削っても支障ない範囲を探る
- ボーカルとぶつかるなら、ダイナミックEQでダック（[サイドチェイン実践](06a-sidechain-recipes.md)）

## ボーカル

| 操作 | 周波数 | 目安 |
|---|---|---|
| ハイパス | 男声80–100Hz / 女声100–150Hz | |
| カット | 200–400Hz | こもり（必要な分だけ） |
| カット | 500–800Hz | 鼻詰まり感 |
| ブースト | 2–5kHz | 明瞭度、抜け |
| ブースト（シェルフ） | 8–12kHz | 空気感、艶 |

- **高域をブーストしたら、その後にディエッサーを置く**（サ行も一緒に増えるため）
- 特定の音程だけ膨らむ場合はダイナミックEQ
- 詳細は[ボーカルチェーンの実例](13a-vocal-chain.md)
