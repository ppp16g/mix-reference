# 18 マスタリングとラウドネス

## マスタリングとは何か

**ミックスの延長ではなく、別の工程。** 目的は3つ。

1. 曲を配信／再生に耐える最終的な形に整える
2. 複数曲を並べたときの統一感（アルバム／EP）
3. 再生環境をまたいだ互換性の確保

**ミックスの問題はマスタリングでは直らない。** 直したくなったらミックスに戻る。

## 自分でやる場合の心構え

- **ミックスとは日を分ける。** 同じ耳で連続してやると判断が甘くなる
- **±1–2dBの世界。** 大きく動かしたくなったらミックスの問題
- リファレンス曲との比較が全て（音量を揃えて）

## 典型的なチェーン

順序に絶対はないが、一例。

1. **修正EQ** — 問題の除去。狭Qのカット、不要な低域
2. **コンプ** — GR 1–2dB。全体の接着
3. **音作りEQ** — シェルフで±1dB程度の色付け
4. **サチュレーション** — ごく軽く、密度
5. **ステレオ処理** — Side低域のモノ化など（[定位とステレオイメージ](08-stereo.md)）
6. **リミッター** — 音圧の最終調整
7. **ディザ** — 16bitに落とす場合のみ、必ず最後

## ラウドネス（LUFS）

- **LUFS** = 知覚音量の単位。**Integrated LUFS**（曲全体の平均）が主要な指標
- 配信サービスは自動で音量を揃える（ラウドネスノーマライゼーション）ため、**過剰に音圧を上げても再生時に下げられるだけ**。ダイナミクスを失って損をする
- 各サービスの基準値は変わりうるので、**最新の情報を確認すること**。一般に **-14 LUFS 前後** が広く言及される基準
- **True Peak** はインターサンプルピークを含む値。歪みを避けるため **-1.0 dBTP** 程度に抑えるのが一般的（ロッシー圧縮での歪み対策）

### 実務的な結論
- **数字を目標にしない。** ジャンルと曲に合った音圧がある。バラードとEDMで同じ数字を目指す必要はない
- リミッターのGRは 2–4dB 程度までが自然。それ以上潰すなら、その音圧が本当に必要か考える
- ラウドネスメーターで Integrated LUFS と True Peak を確認する習慣をつける

## 最終書き出し

- 配信用：WAV 24bit、サンプルレートは元のまま（44.1kHz または 48kHz）
- CD用：WAV 16bit / 44.1kHz、**ディザあり**
- 書き出したファイルを**必ず通しで聴く**。書き出し時のミスは実際に起きる

## 外注を検討すべきとき

- 複数曲をアルバムとしてまとめる
- 商業リリースで、自分の環境の精度に不安がある
- 自分のミックスに客観性を持てなくなっている

第三者の耳が入ること自体に価値がある。
