# 15 バス構成とミックスバス

## なぜバスを作るか

1. **一括で音量を動かせる**（ドラム全体を1dB下げる、など）
2. **バス単位で処理して、まとまりを作る**（バスコンプ、サチュレーション）
3. **セッションが見通しよくなる**

## 基本構成

```
[各トラック]
   ├─→ Drum Bus ─┐
   ├─→ Bass ─────┤
   ├─→ Gtr Bus ──┼─→ Mix Bus ─→ Master
   ├─→ Key Bus ──┤
   ├─→ Vox Bus ──┘
   │
   └─→ (Send) → FX ch (Reverb / Delay) ─→ Mix Bus
```

- **Mix Bus を Master とは別に作る。** マスターは書き出し用に空けておくと、マスタリング段との切り分けが楽
- FXチャンネルの出力先をMix Busにするか個別にするかは好みだが、統一しておく
- Studio One／Fender Studio Pro では Bus チャンネルと FX チャンネルを使い分ける

## VCAフェーダー

- グループの相対バランスを保ったまま、全体音量を動かせる
- バスと違い、**音は通らない**ので、バス処理には影響しない
- 例：ドラムバスにバスコンプを挿していると、フェーダーを下げるとコンプの効き方が変わる。VCAならコンプへの入力レベルは変えずに出力音量だけ動かせる
- オートメーションで曲全体を動かすときに特に有効（[オートメーション](10-automation.md)）

## バス処理

### ドラムバス
- バスコンプ GR 2–4dB、アタック遅め（30ms前後）、リリースはテンポ同期
- パラレルコンプ（[コンプとダイナミクス](05-compression.md)）
- サチュレーション（[サチュレーションと音の密度](07-saturation.md)）

### ボーカルバス
- メイン／ダブル／ハモをまとめて、軽いコンプで一体化
- バス側でリバーブへ送ると、ボーカル群が同じ空間に収まる

### ミックスバス
**ここは「軽く」が鉄則。**

- **バスコンプ：GR 1–3dB程度。** Ratio 2:1、アタック遅め、リリース速め〜テンポ同期
- **EQ：±1–2dB以内。** 大きく動かしたくなったら、個別トラックに戻る
- **サチュレーション：ごく軽く**
- **リミッターは基本挿さない**（マスタリング段の仕事）。挿すなら、確認用として最後に置き、書き出し時は外す

### ミックスバス処理を「先に」挿す
最初からミックスバスにバスコンプを挿しておき、その状態でミックスを進める手法がある。後から挿してバランスが崩れるのを防げる。ただし**軽く**が前提。

## モニター用のツール

- Mix Bus の最後に、モノ化やリファレンス比較用のプラグインをチェーン
- **書き出し前に必ず外す／バイパスする**
