# 02 下ごしらえ（整音と整理）

ミックスを始める前の30分が、その後の数時間を決める。

## セッションの整理

- **トラック名を全部つける。** 「Audio 12」のままにしない
- **色分け。** ドラム／ベース／ギター／鍵盤／ボーカル／FX で色を統一
- **トラック順を固定。** 上から ドラム → ベース → 楽器 → ボーカル → FX が一般的
- **バスを先に作る。** 詳細は [バス構成とミックスバス](15-bus.md)
- **不要なトラックは削除かディアクティブ。** 「使うかも」は迷いの元

## 編集の掃除

- **全リージョンの頭と尻にフェードをかける。** クリックノイズの最大の原因
- **不要な無音区間をカット。** アンプノイズ、椅子の音、息継ぎ以外の雑音
- **タイミング／ピッチ修正はミックス前に終わらせる。** ミックス中に「なんか気持ち悪い」の正体がタイミングだった、が非常に多い

## 位相の確認（低域の要）

これを飛ばすと、後段でどれだけEQしても低域が決まらない。

- **マルチマイク録音**（キック内／外、スネア上／下、ギターアンプ2本）は必ず確認する
- 確認方法：2本を同時に鳴らし、片方の位相を反転して、**低域が減る方が正しい**（増える方が逆相）
- Studio One／Fender Studio Pro なら Mixtool の位相反転を使う
- サンプルレベルのズレは、波形を拡大して手で揃えるのが確実
- ベースをDIとアンプの2系統で録っている場合も同様

## ノイズ処理

- ハムノイズ（50/60Hzとその倍音）は狭いQのノッチで
- ヒスノイズはノイズリダクションか、使っていない区間のミュート／オートメーション
- **ノイズ除去はやりすぎると音が痩せる。** 全体で聴いて気にならないなら放置でよい

## 最初のラフバランス

プラグインを一切挿さず、フェーダーとパンだけでバランスを取る。

- ここで「曲として成立している」状態まで持っていけるのが理想
- 成立しないなら、**それはミックスの問題ではなくアレンジの問題**。アレンジに戻る
- このラフバランスはバウンスして残しておく。迷ったときの原点になる
