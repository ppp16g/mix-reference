# 16 トラブル逆引き（症状 → 原因 → 対処）

## 全体

**こもる／曇る**
- 200–500Hzの累積過多 → 各トラックでこの帯域をカット
- ハイパス不足 → 中域楽器のハイパスを見直し（[ギター・シンセ・鍵盤](14-guitar-synth-keys.md)）
- 高域が足りない → 足す前に、低〜中域を削って相対的に上げる

**うるさいのに迫力がない**
- 中高域が過多、低域の土台がない → [低域（キックとベース）](11-low-end.md)
- コンプのかけすぎでダイナミクスが消えている → [コンプとダイナミクス](05-compression.md)
- 全部が同じ音量で並んでいる → 前後の設計（[定位とステレオイメージ](08-stereo.md)）とオートメーション（[オートメーション](10-automation.md)）

**平坦、単調**
- オートメーション不足 → [オートメーション](10-automation.md)
- 全部にリバーブが同量 → [空間系（リバーブとディレイ）](09-reverb-delay.md)
- セクション間の差がない → アレンジに戻る

**濁る、混沌としている**
- 音数が多すぎる → アレンジで削る
- 帯域が住み分けていない → [EQ](04-eq.md), [ギター・シンセ・鍵盤](14-guitar-synth-keys.md)
- リバーブ過多 → [空間系（リバーブとディレイ）](09-reverb-delay.md)

**音量を上げると破綻する**
- 低域の一部が突出 → アナライザーとハイパスで整理
- ミックスバスのゲイン構造 → [準備とモニタリング](01-monitoring.md)
- 位相の問題 → [下ごしらえ（整音と整理）](02-prep.md)

## 低域

**低音がぼやける／位置が分からない**
- キックとベースの役割分担が未決定 → [低域（キックとベース）](11-low-end.md)
- 位相の問題 → [下ごしらえ（整音と整理）](02-prep.md)
- 部屋の影響で判断を誤っている → ヘッドホンとリファレンスで確認（[準備とモニタリング](01-monitoring.md)）

**スマホで低音が聞こえない**
- 倍音不足 → ベースにサチュレーション（[サチュレーションと音の密度](07-saturation.md), [低域（キックとベース）](11-low-end.md)）

**キックが埋もれる**
- ベースが同じ帯域を占領 → 相補的EQ（[低域（キックとベース）](11-low-end.md)）
- アタックが不足 → トランジェントシェイパー、または2–5kHzを足す

**低域が多すぎる／膨らむ**
- 各トラックのハイパス不足
- 部屋で低域が聞こえず、足しすぎている → リファレンス比較

## ボーカル

**埋もれる** → [ボーカル](13-vocals.md) のチェック順を参照

**耳に刺さる／サ行がきつい**
- ディエッサー（[ボーカル](13-vocals.md)）
- 3–6kHzのブーストのしすぎ

**こもる**
- 200–400Hzの過多
- リバーブが多く、暗い

**不自然、機械的**
- コンプのかけすぎ → オートメーションで揃えてからコンプ（[オートメーション](10-automation.md), [ボーカル](13-vocals.md)）
- ピッチ補正のかけすぎ

## ドラム

**バラバラに聞こえる** → バスコンプとルーム／リバーブの共有（[ドラム](12-drums.md), [バス構成とミックスバス](15-bus.md)）

**キックとスネアがぶつかる** → 帯域の住み分け

**ハットがうるさい** → ハイパスを高めに、音量を下げる、ダイナミックEQ（[ドラム](12-drums.md)）

## 空間系

**リバーブが濁る** → [空間系（リバーブとディレイ）](09-reverb-delay.md) の対処リスト

**広げたはずが薄くなった**
- ステレオワイドナーによる位相干渉 → モノ互換確認（[定位とステレオイメージ](08-stereo.md)）
- センターの成分が減っている

**モノにすると音が消える／変わる**
- 逆相 → [下ごしらえ（整音と整理）](02-prep.md)
- ステレオ拡張系プラグイン → [定位とステレオイメージ](08-stereo.md)

## 判断できないとき

- 耳が疲れている → 休む
- リファレンスと比較していない → [準備とモニタリング](01-monitoring.md)
- 環境を1つしか使っていない → 別環境で聴く
- **ミックスの問題ではなくアレンジの問題** → その可能性を常に検討する
